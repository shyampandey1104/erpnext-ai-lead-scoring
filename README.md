# 🎯 ERPNext AI Lead Scoring & CRM Conversion Engine

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/ERPNext-CRM-blue.svg)](https://erpnext.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A machine learning & heuristic **Lead Qualification and Scoring Engine** for **ERPNext CRM**. Evaluates inbound leads on company size, industry vertical, channel origin, and behavioral touchpoints (email opens, demos, meetings) to assign conversion probabilities (0-100%) and prioritization tiers (`Hot`, `Warm`, `Cold`).

---

## ⚡ Features
- 📈 Multi-factor lead scoring with explainable factor breakdowns.
- 🎯 Automatic CRM tier categorization (`Hot`, `Warm`, `Cold`).
- 🔄 Updates Frappe `Lead` DocType custom score field via REST API.
- 🧪 Pytest test suite included.
